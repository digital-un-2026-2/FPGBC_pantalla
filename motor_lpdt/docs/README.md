# Protocolo y diagramas del motor

[Motor](../README.md) · [Arquitectura general](../../docs/arquitectura.md)

| Archivo | Contenido |
|---|---|
| `lpdt.md` | Codificación, vector inicial y tiempos de referencia |
| `MOTOR_LPDT.drawio` | Fuente editable de los diagramas |
| `MOTOR_LPDT.pdf` | Exportación de las tres páginas |
| `flujo.svg`, `datapath.svg`, `fsm.svg` | Vistas para consultar en GitHub |

Son documentos y dibujos, no bloques adicionales de hardware. El contrato RTL
del README superior prevalece sobre los diagramas conceptuales.

Para regenerar PDF/SVG hacen falta Draw.io y Poppler, no incluidos como requisito
de simulación. Los comandos están en [Diagramas](../README.md#diagramas).
Editar el `.drawio` primero, no retocar las exportaciones para cambiar el diseño.
